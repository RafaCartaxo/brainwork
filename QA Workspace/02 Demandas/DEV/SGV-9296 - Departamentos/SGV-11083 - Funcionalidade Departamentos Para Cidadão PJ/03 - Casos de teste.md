### A. Criação de departamento

> [!example]- CT-001 · Departamento só é criado para cidadão PJ
>
> ```meta-bind-button
> style: primary
> label: ↩ Validação
> action:
>   type: open
>   link: "[[04 - Validação dev#Resultado dos casos de teste]]"
> ```
>
> ## Cenário
>
> **Descrição:** confirma que o sistema não permite criar um departamento para cidadão do tipo Pessoa Física.
>
> **Pré-condições:**
> - Servidor está cadastrando um departamento.
>
> **Dado** que um servidor está cadastrando um departamento
> **Quando** seleciona um cidadão do tipo Pessoa Física
> **Então** o sistema não permite a criação do departamento
>
> **Resultado esperado:** criação bloqueada para Pessoa Física.
>
> **Pós-condição:** nenhuma.
>
> **Critérios cobertos:** [[QA Workspace/02 Demandas/DEV/SGV-9296 - Departamentos/SGV-11083 - Funcionalidade Departamentos Para Cidadão PJ/01 - Demanda#^c1|C1]]
