# Planejamento

Acompanhamento de sprints ativas — como a daily note, mas no escopo de sprint. Cada sprint é uma página única, escaneável de relance.

## Sprints ativas

| SP16 | — | — | — |

> [!tip] Como usar
> Abra a página da sprint e role as seções como faria com a daily — cada seção é um estágio QA (Ação imediata → Em validação → Aguardando deploy → A revisar → Aguardando terceiros → Acompanhamento). A numeração (`🔴🔴 Homologação (3)`) mostra o volume de cada bloco de uma vez.

## Como nasce uma página de sprint

1. Exportar a view do Notion (`sprint-N.md`)
2. Pedir "processa o material novo" — o [[../../Sistema/Agentes/AGENTE_PROCESSAR_EXPORT|AGENTE_PROCESSAR_EXPORT]] classifica
3. Se for triagem de sprint → [[../../Sistema/Skills/SKILL_TRIAGEM_SPRINT|SKILL_TRIAGEM_SPRINT]] cria a página em `Planejamento/SP<N>.md`
